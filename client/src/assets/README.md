# Assets

- brand/: logo.svg, wordmark.svg and logo-icon.svg. Prefer outlined SVG text to avoid font dependency.
- mascot/: transparent SVG, PNG or WebP mascot files. Use descriptive pose names.
- illustrations/: page artwork and decorative images.
- client/public/: files served by fixed URL, such as favicon.svg.

Import assets from React or CSS so Vite manages their paths. Do not place API keys or personal uploads here. Current bee is an inline SVG in components.tsx; replacement assets have not been supplied yet.
